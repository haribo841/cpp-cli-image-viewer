# Usage guide

## Current workflow

1. Start the Windows Forms application from Visual Studio.
2. Choose Open Image.
3. Select a local image in the file dialog.
4. The selected file is loaded with System.Drawing and shown in the PictureBox.

After a successful load, the Open Image button is disabled for that form instance. Restart the application to choose another image.

## Reproduce the README example

Build the `Debug | x64` configuration, start `x64/Debug/Project1.exe`, and open `docs/images/sample-color-bars.png`.
The fixture contains eight solid color bars and is generated by `docs/create-sample-image.ps1`.
The README capture was taken from the actual Windows Forms application, not a design mockup.

Validated on Windows with Visual Studio 2022, MSVC v143, and .NET Framework 4.8. The project file includes the C++ source, header, and required framework references.

On 2026-10-01, Debug and Release builds passed for both x64 and x86 (Win32). The existing entry point in `MainForm.cpp` still produces compiler warning C4829; the documentation/build-configuration update does not change application source code.

## Current scope

This is an image-loading prototype. The repository does not currently implement:

- filters, enhancement, cropping, or export;
- multiple-image selection;
- cross-platform support; or
- automated tests.

The PictureBox uses its default display mode rather than a fit-to-window mode, so an image larger than the control can be clipped. The included 640 x 480 test fixture makes this limitation visible on scaled displays. This prototype is not an image editor.

The application opens a local file, so use only image data that may be viewed on the development machine.
